# その他の Claude Code コマンド (etc)

このドキュメントでは、`etc`ディレクトリ配下の単体動作コマンドについて解説します。これらのコマンドは特定の用途に特化した軽量なワークフローを提供します。

## 🔍 リサーチ・分析系コマンド

### research.md - 究極のリサーチアシスタント

**用途**: 技術調査・情報収集・比較分析
**対象**: 新技術、ツール、フレームワーク、問題解決

**主な機能**:

- 多角的な情報収集（公式ドキュメント、技術記事、GitHub Issues 等）
- 自動判定による適切な成果物生成
- カテゴリ別の構造化された保存

**成果物タイプ**:

- 📋 技術調査レポート（新技術・ツール・フレームワーク向け）
- 🛠️ 実装ガイド（How-to 系）
- 🐛 問題解決プレイブック（エラー・トラブル系）
- 📊 比較分析レポート（選択肢の比較）
- 🚀 クイックスタートキット（入門・始め方）

**使用例**:

```
/etc:research topic:"React Server Components" source:"https://nextjs.org/docs" detail:"パフォーマンス影響の調査"
```

### error-analysis.md - Sentry エラー解析

**用途**: Sentry で報告されたエラーの詳細分析と報告書作成
**対象**: 本番環境エラー、バグ調査、インシデント対応

**主な機能**:

- Sentry MCP サーバーを使用した詳細エラー情報取得
- 構造化された分析レポート生成
- 時間の自動変換（CET → JST）
- 類似エラーの過去事例調査

**生成レポート項目**:

- 事象・原因・影響範囲
- バージョン情報・再現手順
- 暫定・恒久対策
- GitHub 該当箇所・類似エラー

## 推奨する使い分け

### 調査・分析タスク

- **research.md** - 技術調査、比較分析
- **error-analysis.md** - エラー分析、バグ調査
