# Go-Challenge インターフェース仕様書

## 用語集

| 用語 | 説明 |
|------|------|
| CPO | Charging Point Operator（充電ポイント運営者） |
| EV | Electric Vehicle（電気自動車） |
| EVSE | Electric Vehicle Supply Equipment（電気自動車供給設備）。一度に1台のEVにエネルギーを供給できる、充電ポイントの独立して運用・管理される部分として考えられる。 |
| Location | LocationオブジェクトはCPOのバックエンドシステムに存在する。運営者の充電ロケーションを記述する。 |

## カーディナリティ（多重度）

| 記号 | 説明 | 型 |
|------|------|-----|
| ? | オプションのオブジェクト。設定されていない場合、フィールドは省略される。 | Object |
| 1 | 必須オブジェクト | Object |
| * | 0個以上のオブジェクトのリスト。空の場合、フィールドは省略される。 | [Object] |
| + | 1個以上のオブジェクトのリスト。 | [Object] |

---

## エンドポイント

### Locations エンドポイント

指定された {latitude}（緯度）、{longitude}（経度）、{radius}（半径）で定義された円形エリア内のロケーションリストを取得するエンドポイントを提供する。

### URI

```
api/locations?[latitude={latitude}]&[longitude={longitude}]&[radius={radius}]&[date_from={date_from}]&[date_to={date_to}]
```

### リクエストメソッド

GET

### リクエストパラメータ

| パラメータ | データ型 | 必須 | 説明 |
|-----------|---------|------|------|
| latitude | string(11) | yes | 小数点形式の緯度。例: 50.770774。小数点区切り: "." 正規表現: `-?[0-9]{1,2}\.[0-9]{5,7}` |
| longitude | string(12) | yes | 小数点形式の経度。例: -126.104965。小数点区切り: "." 正規表現: `-?[0-9]{1,3}\.[0-9]{5,7}` |
| radius | int | no | 緯度・経度からの検索半径。単位: km。指定されない場合、デフォルトは100kmに設定される。 |
| date_from | DateTime | no | この日時以降（含む）に last_updated が更新されたLocationのみを返す。 |
| date_to | DateTime | no | この日時より前（含まない）に last_updated が更新されたLocationのみを返す。 |

### レスポンスデータ

| 型 | 多重度 | 説明 |
|----|--------|------|
| Location | * | EVSEを含むすべてのLocationのリスト。 |

## オブジェクト定義

LocationとEVSEは以下の関係を持つ。

```
┌─────────────┐
│  Location   │
└──────┬──────┘
       │ 1
       │
       │ 0..n
┌──────┴──────┐
│    EVSE     │
└─────────────┘
```

### Location オブジェクト

| プロパティ | データ型 | 多重度 | 説明 |
|-----------|---------|--------|------|
| id | string(36) | 1 | LocationのユニークID |
| name | string(255) | ? | Locationの名前 |
| address | string(45) | 1 | Locationの住所 |
| coordinates | GeoLocation | 1 | 緯度と経度を含む座標オブジェクト |
| evses | EVSE | * | EVSEオブジェクトの配列。EVSEは充電ステーションに接続された充電器を表す。 |

### EVSE オブジェクト

| プロパティ | データ型 | 多重度 | 説明 |
|-----------|---------|--------|------|
| uid | string(36) | 1 | CPOのプラットフォーム内でのEVSEのユニーク識別子。 |
| status | Status | 1 | EVSEの現在のステータス。"AVAILABLE"、"BLOCKED"、"CHARGING"など。 |

## データ型

### GeoLocation クラス

| プロパティ | データ型 | 多重度 | 説明 |
|-----------|---------|--------|------|
| latitude | string(11) | 1 | 小数点形式の緯度。例: 50.770774。小数点区切り: "." 正規表現: `-?[0-9]{1,2}\.[0-9]{5,7}` |
| longitude | string(12) | 1 | 小数点形式の経度。例: -126.104965。小数点区切り: "." 正規表現: `-?[0-9]{1,3}\.[0-9]{5,7}` |

### Status 列挙型

| 値 | DB値 | 説明 |
|----|------|------|
| AVAILABLE | 1 | EVSE/コネクタは新しい充電セッションを開始できる状態。 |
| BLOCKED | 2 | EVSE/コネクタは物理的な障害（例: 車両）のためアクセスできない。 |
| CHARGING | 3 | EVSE/コネクタは使用中。 |
| INOPERATIVE | 4 | EVSE/コネクタはまだアクティブでないか、一時的に使用できないが、故障や欠陥ではない。 |
| OUTOFORDER | 5 | EVSE/コネクタは現在故障中。一部の部品/コンポーネントが壊れている可能性がある。 |
| PLANNED | 6 | EVSE/コネクタは計画中で、まもなく運用開始予定。 |
| REMOVED | 7 | EVSE/コネクタは廃止/撤去された。 |
| RESERVED | 8 | EVSE/コネクタは特定のEVドライバー用に予約されており、他のドライバーは利用不可。 |
| UNKNOWN | 9 | ステータス情報が利用できない（オフライン時にも使用）。 |

### DateTime 型

すべてのタイムスタンプは RFC 3339 に従った string(25) 形式でフォーマットされる（いくつかの追加制限あり）。

すべてのタイムスタンプは UTC でなければならない。タイムゾーン指定子がない場合は UTC タイムスタンプを意味する。小数秒を使用してもよい。

OCPIでのタイムスタンプフォーマット例（他のフォーマット/パターンは許可されない）:

```
2015-06-29T20:39:09Z
2015-06-29T20:39:09
2016-12-29T17:45:09.2Z
2016-12-29T17:45:09.2
2018-01-01T01:08:01.123Z
2018-01-01T01:08:01.123
```

**注意**: `+00:00` は UTC と同じではない。
